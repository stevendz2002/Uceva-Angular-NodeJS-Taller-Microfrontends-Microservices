# Microfrontend-Tickets-Angular

Microfrontend para el dominio de **Tickets de Soporte Técnico** desarrollado con Angular 20 y Webpack Module Federation.

- **Puerto:** `4205`
- **Remote Entry:** `http://localhost:4205/remoteEntry.js`
- **Módulo expuesto:** `./TicketsPage`

## Comandos

- `npm run start`: Inicia el servidor de desarrollo en el puerto 4205.
- `npm run test`: Ejecuta las pruebas unitarias con Jest.
- `npm run test:coverage`: Genera el reporte de cobertura con Jest (>90%).
- `npm run compodoc`: Genera la documentación técnica con Compodoc.
